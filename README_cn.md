# Pomodoro Timer 番茄钟

**语言: [English](README.md) | [中文](README_cn.md)**

一款为高效工作设计的番茄钟应用，采用极简UI界面，帮助用户更好地管理工作专注时间和休息时间。

## ✨ 功能特点

- **极简界面**: 界面简洁无干扰，高可见性，符合人体工程学的按钮尺寸

- **智能计时**: 标准25分钟专注 + 5分钟休息循环

- **视觉反馈**: 不同状态由不同背景色指示，直观的状态识别

- **进度条**: 背景颜色渐变作为视觉进度指示器
  
- **数据追踪**: 实时显示累计专注和休息时长

- **智能提醒**: 震动和屏幕闪烁双重提醒

- **深度专注模式**: 提醒仅震动两次，随后切换至静默的颜色编码状态

- **全屏控制**: 点击屏幕上任意位置作为主交互按钮

## 📱 功能描述

### 专注倒计时 (25分钟，绿色背景)

- 25分钟专注倒计时，绿色背景表示活跃的专注模式

- 大字体显示剩余时间，便于远距离查看

- 进度条: 背景颜色渐变作为视觉进度指示器

### 专注暂停 (橙色背景)

- 暂停时背景变为橙色

- 显示累计专注和休息时间统计

- 暂停时长计入总休息时间

![Screenshot_20260113_121730_com example pomodoro](https://github.com/user-attachments/assets/b4c019f0-9ad4-4339-ac24-960e29e38287  )

### 专注完成 (黄色背景 – 等待休息)

- 专注时段结束时屏幕闪烁两次并震动

- 进入正向计时模式，背景为黄色

- 等待用户操作开始休息时段

![Screenshot_20260113_121850_com example pomodoro](https://github.com/user-attachments/assets/62ee229e-106a-4557-a9e2-b8f122af7a06  )

### 休息倒计时 (5分钟，橙色背景)

- 5分钟休息倒计时

- 允许查看累计专注/休息统计而不中断倒计时

- 休息倒计时尚不能暂停

- 进度条: 背景颜色渐变作为视觉进度指示器

![Screenshot_20260113_121856_com example pomodoro](https://github.com/user-attachments/assets/6d43152c-9e6f-46f1-a0c6-c759b43dfd5d  )

### 休息查看统计 (橙色背景)

- 休息时背景变为橙色

- 显示累计专注和休息时间统计

- 查看统计不会停止休息倒计时

![Screenshot_20260113_121859_com example pomodoro](https://github.com/user-attachments/assets/40869d66-de9d-4a92-a340-b8bb52fe6f2d  )

### 休息完成 (黄色背景 – 等待专注)

- 休息时段结束时震动提醒

- 进入等待状态，准备开始下次专注时段

- 此时长计入总休息时长

![Screenshot_20260113_121905_com example pomodoro](https://github.com/user-attachments/assets/e2912bda-eeef-4cdc-8745-f78ca237f2e3  )

### 智能日期处理

- 为适应通宵工作，每天计时从凌晨5:00开始

## 🔮 未来功能路线图

### 暂停期间动态时间

- 暂停时，累计休息时间实时动态更新

### 📊 历史记录

- 存储每日工作和休息时长

- 在主页显示历史图表

- 双色柱状图：底部绿色（工作时间），顶部橙色（休息时间）

- 实现工作时间与总时间趋势的直观对比

### 🔄 自适应休息时长

- 实现每2小时一次长休息机制

- 基于过去2小时内的总休息时间动态调整休息长度

- 若休息时间≥阈值（如30分钟），使用5分钟短休息；否则触发25分钟长休息

### ⚙️ 可调专注时长

- 主页滚动轮调整专注时长

- 支持自定义默认25分钟专注时段

### 📱 UI优化

- 研究定制化布局设计以适应个人工作流需求

- 添加竖屏模式支持

- 基于重力传感器支持方向适配（充电口在左或右）

### 🌍 多语言支持

- ReadMe文档和UI文本支持中英文切换

### 🔒 专注锁定模式

- 启用强制专注模式

- 激活时，专注期间设备锁定：无通知，无应用切换

- 或者，应用切换计入休息时间或增加失败计数

### 强制停止

- 强制停止专注或休息时间，切换到另一个

## 🛠 技术栈

- **开发语言**: Kotlin

- **UI框架**: Android XML + ConstraintLayout

- **计时引擎**: CountDownTimer

- **数据持久化**: SharedPreferences

## 🚀 安装与使用

1. 下载APK文件

2. 在Android设备上安装

3. 授予震动权限

4. 开始专注高效的工怍！
