# Pomodoro Timer 番茄钟计时器

**语言: [English](README.md) | [中文](README_cn.md)**

一款专为高效工作设计的番茄钟计时器应用，采用简洁的UI设计，帮助用户更好地管理专注时间与休息时间。

## ✨ 特点

- **简洁界面**：UI界面简洁干扰少，可观测性强，按钮适合操作
- **智能计时**：25分钟专注 + 5分钟休息的标准循环
- **视觉反馈**：不同状态对应不同背景色，直观显示当前状态
- **数据统计**：实时显示累计专注和休息时间
- **智能提醒**：震动和屏幕闪烁双重提醒
- **深度专注**：提醒只会震动两次，然后切换颜色静默状态

## 📱 功能描述

### 专注倒计时 (25分钟，绿色背景)
- 25分钟专注倒计时，绿色背景表示正在专注
- 大字体显示剩余时间，便于远距离观察

![专注倒计时](https://github.com/user-attachments/assets/02fc910b-c822-4062-822d-f4e7d5946199)

### 专注暂停 (橙色背景)
- 暂停时背景变为橙色
- 显示累计专注和累计休息信息
- 暂停时间计入休息时间

![专注暂停](https://github.com/user-attachments/assets/4b603c5c-8778-4e72-a8a6-c2eb7eccb08e)

### 专注结束 (黄色背景 - 等待休息)
- 专注时间结束后闪烁屏幕并震动提醒
- 进入正计时状态，背景变为黄色
- 等待用户操作开始休息时间

![专注结束](https://github.com/user-attachments/assets/b114b510-909d-44bd-8fe3-df0fe4cb02c6)

### 休息倒计时 (5分钟，橙色背景)
- 5分钟休息倒计时
- 可查看累计专注和休息统计信息
- 不会暂停休息时间倒计时

![休息倒计时](https://github.com/user-attachments/assets/541355a3-38c8-4188-b3ed-270f940fbc68)

### 休息结束 (黄色背景 - 等待专注)
- 休息时间结束后震动提醒
- 进入等待状态，准备开始下次专注
- 时间计入休息时间统计

![休息结束](https://github.com/user-attachments/assets/2ec7b902-6ee6-4fd8-b8be-7023527f9d08)

### 智能日期处理
- 考虑到连夜工作情况，每日记时从凌晨5点开始

## 🔮 后续功能规划

### 暂停时动态时间
- 暂停时显示累计时间，这里的累积休息时间应动态变动

### 📊 历史记录
- 存储每日工作时间和休息时间
- 主页面显示历史记录图表
- 双色条形图：绿色为工作时间在下，橙色为休息时间在上
- 可直观观察工作时间和总时间变化

### 🔄 动态休息时间
- 每2小时一个大休息机制
- 根据过去2小时内总休息时间动态调整休息长度
- 超过阈值(30分钟)则进入5分钟小休息，否则进入25分钟大休息

### ⚙️ 专注时间调节
- 主页面滚轮调节专注时间长度
- 支持自定义25分钟专注时间

### 🎨 进度条显示
- 整个背景作为进度条
- 从左向右颜色渐变显示时间进度

### 📱 UI优化
- 研究更符合需求的自定义布局
- 增加竖屏适配支持
- 重力感应适配，充电口在左或在右

### 🌍 多语言支持
- ReadMe文档和UI文字支持中英文切换

### 🔒 设备锁
- 设置强制专注模式
- 打开后，专注模式时设备上锁，无通知，不可跳转其他app
- 或者跳转其他app计入休息
- 或者计入失败次数

## 🛠 技术栈

- **开发语言**: Kotlin
- **UI框架**: Android XML + ConstraintLayout
- **计时器**: CountDownTimer
- **数据存储**: SharedPreferences

## 🚀 安装使用

1. 下载APK文件
2. 安装到Android设备
3. 开启振动权限
4. 开始高效专注工作
